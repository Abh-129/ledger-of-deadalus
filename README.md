# The Ledger of Daedalus

CAMS 45 midterm creative project. Spec: see the project brief (Section numbers referenced in code comments).

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # maze + flight self-check
npm run build    # typecheck + production build into dist/
```

Deploy `dist/` to Vercel, Netlify or GitHub Pages (static, no backend). Test the public link in a private window.
Useful URLs: `/?static` shows the no-WebGL fallback page. Settings (gear): Unlock all chapters, Reduced motion, Graphics quality.
